# 천안흥타령춤축제 | 다국어 축제 안내

5개 언어로 프로그램·지도·먹거리와 방문 일정을 연결하는 **개인 개발 웹 서비스**입니다. 공식 주최기관의 서비스라는 의미가 아닙니다.

## 기술 스택

- **React · TypeScript:** 사용자 인터페이스와 방문 흐름
- **Vite:** 프런트엔드 개발·빌드
- **MapLibre:** 행사장·주차장·화장실 등 지도 탐색
- **Vercel:** 웹 서비스 배포

## 주요 구현 범위

- 한국어·영어·일본어·중국어·아랍어 안내
- 화면 이동과 공유 URL에서 언어·방문 조건 유지
- 방문 날짜·시간·동행 유형·예산에 따른 규칙 기반 추천
- 공연 시간·장소 충돌, 취소·시간 미공개 상태 구분
- 내 일정 저장·캘린더 내보내기·저장된 안내의 오프라인 열람

## 현재 단계와 한계

공개 안내 서비스이며 일부 운영 기능은 추가 연동이 필요한 단계입니다. **방문 추천은 규칙 기반이며 생성형 AI API를 연결한 서비스가 아닙니다.** 실시간 군중 밀집도나 저장된 안내의 최신성을 보장하지 않습니다.

공개 포트폴리오에는 2026-09-30 기준 다국어·방문 일정 검증 스크립트 2개 통과가 기록되어 있습니다. 외부 API의 현재 가용성이나 운영 기능 전체를 검증한 결과가 아니며, 이번 소개 문서 추가에서 이를 재실행하지 않았습니다.

이 저장소는 **프로젝트 소개 문서 전용**입니다. 소스 코드와 예제 코드, 실행 파일, 모델 파일, 데이터셋, 운영 설정, API 키는 공개하지 않습니다. 원본 저장소 및 커밋 이력을 복제하거나 연결하지 않습니다.

공개 포트폴리오와 확인된 프로젝트 메타데이터를 바탕으로 기술 스택·기능·현재 단계를 요약했습니다. 실제 운영 성과나 전체 기능 검증을 의미하지 않습니다.
